# نظام إدارة المبيعات والمشتريات والمخزون والديون

نظام عربي (RTL) متكامل لتجارة الجملة والتجزئة (خضروات وفواكه) مبني على Lovable Cloud لقاعدة البيانات وتسجيل الدخول والصلاحيات.

## الشاشات

1. **لوحة اليوم (الرئيسية)** — ملخص حركة اليوم: مبيعات، مشتريات، مصروفات، صافي الربح، إجمالي الديون.
2. **المبيعات** — إنشاء فاتورة بأصناف متعددة (كيلو/خيشة/صندوق)، نقدي أو آجل، اسم العميل ورقم هاتفه. الإجمالي يُرحّل تلقائياً لكشف الإجماليات.
3. **المشتريات والموردين** — تسجيل شحنات واردة، تحديث المخزون وسعر التكلفة، ديون مستحقة للموردين.
4. **الإجماليات والديون (كشف اليوم)** — جدول: رقم الفاتورة، التاريخ، النوع، الاسم، الهاتف، الإجمالي، المدفوع، المتبقي، وزر واتساب لإرسال مطالبة جاهزة + زر كشف حساب تفصيلي للعميل/المورد.
5. **المصروفات والإيجارات** — مصاريف تشغيل (نقل، عمالة، ثلج، كهرباء)، إيجار شهري وأقساط دورية.
6. **الهالك والجرد** — تسجيل التالف يومياً، جرد دوري ومطابقة الكميات.
7. **السلف ومسحوبات المالك** — حسابات مستقلة لا تدخل في صافي الربح التشغيلي.
8. **التقارير** — يومي/شهري حسب المعادلة: صافي الربح = المبيعات − (تكلفة المشتريات + المصروفات والإيجار + الهالك).
9. **الإعدادات** — بيانات المنشأة، قوالب رسائل واتساب بمتغيرات (اسم العميل، المبلغ، التاريخ)، إدارة المستخدمين والصلاحيات.

## الصلاحيات

- **بائع**: إدخال فواتير المبيعات فقط.
- **مدير**: كل شيء (الأسعار، المصروفات، الأرباح، الإعدادات، المستخدمين).

## رسائل واتساب

زر لكل فاتورة يفتح `wa.me` برسالة مُعبّأة من القالب المحفوظ (بدون الحاجة لأي اشتراك خارجي).

## التفاصيل التقنية

- Lovable Cloud (قاعدة بيانات + تسجيل دخول). جداول: `customers`, `suppliers`, `products`, `invoices`, `invoice_items`, `purchases`, `purchase_items`, `payments`, `expenses`, `waste`, `stock_counts`, `advances`, `owner_withdrawals`, `settings`, `profiles`, `user_roles`.
- الأدوار في جدول `user_roles` منفصل مع دالة `has_role` وسياسات RLS.
- الفواتير مرتبطة بالبنود عبر `invoice_id`؛ المتبقي = الإجمالي − مجموع الدفعات.
- واجهة RTL بالكامل، خط عربي واضح، تصميم عملي بجداول كثيفة مناسب للاستخدام اليومي على الجوال.

## مراحل التنفيذ

1. تفعيل Cloud + قاعدة البيانات + الدخول والصلاحيات + التخطيط العام RTL.
2. المبيعات والفواتير التفصيلية + كشف الإجماليات وأزرار واتساب.
3. المشتريات والموردين والمخزون.
4. المصروفات، الهالك والجرد، السلف والمسحوبات.
5. التقارير وشاشة الإعدادات.
